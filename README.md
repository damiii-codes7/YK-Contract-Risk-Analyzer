# Contract Risk Analyzer

An AI-powered legal-tech application designed to identify and highlight potentially risky clauses in contracts and legal agreements.

## Features

* Upload and analyze contracts instantly
* Detect high-risk clauses such as:

  * Indemnity clauses
  * Arbitration provisions
  * Termination conditions
  * Liability limitations
  * Payment obligations
* Simplify contract review workflows
* Assist legal professionals, startups, and businesses in preliminary risk assessment

## Why I Built This

Traditional contract review is time-consuming and often repetitive. This project explores how AI-assisted workflows can improve legal review efficiency while supporting faster identification of contractual risks and obligations.

## Tech Stack

* Python
* Generative AI / LLM APIs
* NLP-based text analysis
* Streamlit / Flask
